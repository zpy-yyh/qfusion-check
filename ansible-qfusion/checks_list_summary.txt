基础系统检查 (1-10)
================================================================================

 1. ✅ 操作系统检测
     - 支持系统: RedHat 7.8/7.9、CentOS 7.x、麒麟V10 SP3
     - 检测项: 系统类型、版本、架构(x86_64/ARM64)
     - 实现方式: Ansible Facts

 2. ✅ 内核版本检查
     - 要求版本: ≥ 4.19
     - 差异处理: 麒麟系统无需升级
     - 实现方式: uname -r + Jinja2版本比较

 3. ✅ YUM源配置检查
     - 检查项: 仓库目录、文件数量、可用性
     - 实现方式: Stat + Shell

 4. ✅ 硬件时间同步检查
     - 检查项: hwclock命令可用性
     - 实现方式: Command模块

 5. ✅ 网卡速率检查
     - 最低要求: 1000 Mbps
     - 检查范围: 所有物理网卡
     - 实现方式: 读取 /sys/class/net/*/speed

 6. ✅ DNS配置检查
     - 推荐DNS: 114.114.114.114、8.8.8.8
     - 实现方式: 读取 /etc/resolv.conf

 7. ✅ NetworkManager管理检查
     - 检查项: 服务运行状态
     - 实现方式: Systemd模块

 8. ✅ Swap分区检查
     - 要求: Swap应该关闭
     - 实现方式: swapon --show + Facts

 9. ✅ SELinux检查
     - 要求: SELinux应该禁用
     - 实现方式: getenforce + SELinux模块

10. ✅ I/O调度算法检查
    - 推荐算法: deadline
    - 检查范围: 所有块设备
    - 实现方式: 读取 /sys/block/*/queue/scheduler

================================================================================
高级系统检查 (11-20)
================================================================================

11. ✅ Auditd检查
    - 要求: Auditd应该停止
    - 实现方式: Systemd模块

12. ✅ 主机名格式检查
    - 规范: 小写字母、数字、连字符，≤63字符
    - 实现方式: Facts + 正则表达式

13. ✅ 必需软件包检查
    - 检查包: bash、openssh、net-tools、lsof、vim、wget、curl、rsync
    - 实现方式: Package模块

14. ✅ 容器软件冲突检查
    - 冲突软件: docker、docker-engine、docker.io、containerd、runc
    - 实现方式: Package模块

15. ✅ /tmp目录权限检查
    - 要求权限: 1777 (sticky bit)
    - 实现方式: Stat模块

16. ✅ virbr0网卡检查
    - 要求: virbr0应该不存在
    - 实现方式: ip addr show virbr0

17. ✅ CPU AVX指令集检查
    - 检查项: AVX指令集支持
    - 实现方式: 读取 /proc/cpuinfo

18. ✅ 用户资源限制检查
    - 检查项: nofile=65536、nproc=4096/8192
    - 实现方式: ulimit + limits.conf

19. ✅ lsblk与fstab匹配检查
    - 检查项: 设备与fstab配置一致性
    - 实现方式: lsblk + 读取fstab

20. ✅ IPv6状态检查
    - 检查项: IPv6模块和地址配置
    - 实现方式: lsmod + ip -6 addr

================================================================================
专项检查 (21-25)
================================================================================

21. ✅ iptables状态检查
    - 检查项: iptables和ip6tables服务状态
    - 实现方式: Systemd模块

22. ✅ kdump参数检查
    - 要求: kdump应该启用
    - 实现方式: Systemd模块

23. ✅ crashkernel内存检查
    - 要求: crashkernel=4096M,high
    - 实现方式: 读取grub + kdumpctl estimate

24. ✅ 裸盘LVM挂载检查
    - 检查项: LVM和裸盘统计
    - 实现方式: lsblk -o NAME,TYPE,MOUNTPOINT

25. ✅ 麒麟ARM bpf_jit检查
    - 适用系统: 麒麟ARM64
    - 要求: bpf_jit_limit = 264241152
    - 实现方式: sysctl net.core.bpf_jit_limit
